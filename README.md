# .github

Служебный репозиторий организации. Файлы отсюда GitHub подставляет по умолчанию
во все репозитории QodeXSignall, у которых нет собственного файла с тем же именем:

- `PULL_REQUEST_TEMPLATE.md` — шаблон описания Pull Request;
- `CONTRIBUTING.md` — как вносить изменения: форк, ветки, хуки, PR.

Репозиторий обязан быть публичным, иначе GitHub не применяет файлы по умолчанию.
Внутренних ссылок и данных здесь быть не должно.
